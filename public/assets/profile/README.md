# Profile Image Instructions

Place your profile image (`dharmik-profile.jpg`) in this directory. The image should be a clear headshot in a square or near-square format for best results in the circular frames throughout the portfolio.

## Image Placement

The profile image is used in the following components:
1. Hero section (main profile image)
2. Navbar (small avatar)
3. Footer (small avatar)

For best results, use a high-quality image with good lighting and a neutral background.
